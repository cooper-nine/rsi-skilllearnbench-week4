# 产物校验和定向回退

用户确认沿用原十题，在各流程末端校验产物，失败时回到负责生成该产物的节点。地震先校验输出记录和测距复核，股票先校验悬停显示状态。修复阶段接收原始任务数据或之前生成的产物，结果写入新目录。原版 test.sh 及其依赖的测试文件用于整题验收。

第一步接通地震测距和股票悬停。第二步把金融持仓口径和 GDP 公式校验接入各自流程。每题保留人工 Skill 基线、平台运行 ID、节点事件和官方 reward。前端画布仍需验证实际操作。

## 下一阶段的测量方案

人工方案和 LLM 自动编排方案使用同一批输入、预算上限和原版判题。每次修改节点或边、修正输入映射、触发人工重跑，都记录题号、动作、原因和耗时。自动重试和模型发起的回退另记。先在人工方案中实测干预总次数 H0。自动方案先达到全部题目官方通过，再检验干预总次数能否不超过 H0 的一半，并用未参与设计的同类题复验。报告同时给出总次数、每题中位数、人工耗时和原始事件表。
