# 十个典型案例交付

前后端和结果文件使用同一组 case01–case10 编号。各案例只引用对应实例。原始数据由固定提交按需准备。

- 前端 `caseNN.json` 是保存后的画布启动请求，含节点、连线、坐标、契约和题号。画布来自该题的正式记录，启动参数统一为 `mode=fresh` 与单题 `target`，用于重新发起该题。
- 后端 `caseNN.json` 是运行器实际使用的逐题 Skill 执行图，含节点、参考 Skill 原文片段、输入输出提示、边和重试配置。它由 Spring Boot 通用入口 `RSI_WEEK4_CANVAS` 调度。股票第 1–3 题的最终记录是定向续修，执行图沿着实际的来源链取自原始执行，最终续修模式和来源保存在对应结果。
- 结果 `caseNN.json` 记录同题基线与正式官判、运行 ID、原始报告和为什么形成该结果。原始路径均相对总交付仓库根目录。新的模型调用会产生独立试次。
